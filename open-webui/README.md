# Retired Open WebUI configuration

Open WebUI is no longer part of the active Compose stack. Its previous deployment files remain on this branch for reference, but the root [README](../README.md) and [LibreChat configuration](../librechat/librechat.yaml) describe the active deployment.

The previous `open-webui-data` volume is not removed by the new Compose configuration. Its chat history is not migrated to LibreChat.
